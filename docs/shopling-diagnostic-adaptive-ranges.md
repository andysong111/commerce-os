# Shopling 상품 전수진단 적응형 조회 구간

상품마스터와 Shopling 상품·옵션을 대조하는 전수진단은 실제 상품·재고·가격·발주 데이터를 변경하지 않는 읽기 전용 작업이다.

## 조회 범위

- 별도 설정이 없으면 최근 24개 달의 첫날부터 오늘까지 조회한다.
- 신규 실행의 기본 조회 구간은 최대 30일이다.
- 기존 365일 단위 실행이 실패하면 30일 단위 새 실행으로 교체한다.
- 30일 단위 실행도 실패하면 7일 단위로 한 번 더 교체한다.
- 7일 단위 실행도 실패하면 하루 단위로 최종 교체한다.
- 1일 단위 실행까지 실패하면 자동 재접수를 중단해 무한 반복을 방지한다.

## 실패 근거

- 기간, 시도 횟수, 조회 구간 크기와 안전하게 정리한 오류 원인을 불변 실행원장에 남긴다.
- 로그인 ID, 회사 ID, API 인증키 XML과 긴 토큰 형태는 마스킹한다.
- 중첩 오류의 메시지와 코드만 최대 네 단계까지 읽고 전체 문구를 제한한다.

## 쓰기 차단

이 진단과 자동 복구는 다음 작업을 실행하지 않는다.

- 상품마스터 Shopling 연결 저장
- 세트 환산수량 저장
- 재고 및 입고원가 변경
- 가격 변경
- 발주 또는 1688 주문
