# Commerce OS Site 내부화 실행선

이 문서는 기존 ChatGPT Site 3개를 Ops Center 내부 모듈로 전환하는 동안 운영 기준을 고정한다.

## 모듈

1. 발주 추천
2. 중국 발주·입고 관리
3. 상품등급·가격조정

## 전환 규칙

- 기존 Site와 D1은 복구·비교용으로 보존한다.
- Ops Center 내부 경로를 사용자 진입점으로 사용한다.
- 조회와 그림자 계산을 먼저 연결한다.
- 실제 Shopling 가격변경, 1688 주문·결제, 입고확정, 재고변경은 별도 전환 단계 전까지 실행하지 않는다.
- 동일 이벤트는 source_event_id로 멱등 처리한다.
- 브라우저 장시간 작업 대신 서버 원장과 Worker가 처리한다.

## 실행 순서

1. 내부 메뉴·페이지 고정
2. 기존 결과 읽기 및 백업 복원
3. 순수 계산 엔진 이식
4. 판매·재고·발주 원장 어댑터 연결
5. 기존 결과와 그림자 비교
6. Worker 단일화
7. 실제 쓰기 경로 전환
8. 기존 Site 읽기 전용화

## 완료 기준

- 세 기능 모두 Ops Center 내부 URL에서 동작
- 계산 결과의 원인불명 불일치 0개
- 데이터 누락·중복 0개
- 예약 Worker가 기능별 하나만 실행
- 기존 Site 없이 신규 계산·저장·조회 가능
- 실제 쓰기 작업은 사용자 승인과 기존 안전 실행기를 거침
