# 월별 발주 → 배송대행지 바코드 출력

월별 발주·입고 관리의 실제 1688 주문 원장을 기존 `/freight-barcode-request` 기능에 연결한다.

흐름:
1. `/china-order-manager?month=YYYY-MM`에서 `배송대행지 바코드 출력` 단계의 이동 버튼을 누른다.
2. `/freight-barcode-request/monthly?month=YYYY-MM`가 해당 월 `INTERNAL_CHINA_PURCHASE_PREP`의 B-code 연결 주문줄을 읽는다.
3. 주문번호, B-code, 모델번호/모델명, 판매옵션, 중국옵션, 1688 링크, 수량을 세션 컨텍스트로 전달한다.
4. 기존 배대지 바코드 PDF 생성기로 이동한다.
5. 온돌패스 신청서 텍스트를 기존 방식으로 붙여넣고 분석하면 `오픈마켓 주문번호`를 최우선으로 월 주문 원장과 연결한다.
6. 같은 주문번호에 여러 옵션이 있으면 중국옵션/판매옵션/수량/1688 offer ID로 구분하며, 근거가 동률이면 임의 B-code를 넣지 않는다.

컨텍스트는 선택 월과 일치할 때만 적용되며 브라우저 세션 기준 최대 24시간 사용한다.
