# 샵플링 가격설정 Bulk 6단계 계획

## 현재 공식 운영 점수

- 90/100
- 61개 직렬 실행, 실패 상품만 재시도, 일시중지·재접속·재개 운영 검증 완료

## 95점 통과 기준

- 안전한 실제 상품 200~500개 실행
- 카나리 이후 최대 50개 청크 직렬 처리
- 누락·중복 dispatch 0건
- 진행률·청크 경계·처리시간 정확
- 각 청크 첫/중간/마지막 상품과 전체 경계의 Shopling 수정일·가격 표본 확인

## 100점 통과 기준

- 20,000개 가격 무쓰기 검증 작업 저장·재접속·조회 성공
- 검증 전용 작업은 GitHub Actions와 Shopling 쓰기를 구조적으로 실행할 수 없음
- 작업 결과 JSON·상품 상태 CSV·감사 로그 내보내기
- 완료/실패/검증 작업 수동 보관과 오래된 준비 작업 일괄 보관
- 상태 변화 감사 로그와 장애 대응 문서
- 기존 즉시 실행기, 가격 공식, 기존 001~004 migration 무변경

## 안전 원칙

- 실제 가격 쓰기는 기존 live 작업에서 명시적 승인 후에만 수행한다.
- 검증 전용 작업은 별도 상태로 저장하며 모든 실행 버튼을 숨긴다.
- 오래된 작업은 즉시 삭제하지 않고 보관 처리한다.
- 감사 로그에는 Secret, JWT, Authorization, apikey, 원본 대형 payload를 저장하지 않는다.
- 운영 migration은 PR 검수와 Preview 성공 후 수동 적용한다.
