Commerce OS · Shopling Stock State Sync v0.1.7

목적
- Commerce OS 내부 재고수량을 Shopling/마켓의 재고수량과 맞추지 않습니다.
- Commerce OS가 계산한 목표상태가 품절 또는 판매중으로 바뀔 때 Shopling을 통해 마켓 판매상태만 반영합니다.
- Shopling 내부 상품을 정확 B코드/goods key로 좁히고 최종 전송 완료 증거가 있을 때만 성공 처리합니다.

실행 경로
1) 옵션상품
- A6 옵션대량수정: 옵션자체관리코드(B코드) 정확 검색 → 정확 일치 1행만 선택 → 옵션상태 품절/판매중 → 일괄 상태변경
- A21 쇼핑몰상품수정: 방금 수정된 상품의 goods key 정확 검색 → 정확 일치 1행만 선택 → 상품 수정전송 → 옵션송신 선택 → 상품수정 송신 → 옵션전송 최종 완료문구 확인
- 동일 B코드에 활성 goods key가 여러 개면 A6는 1번만 수행하고 A21 옵션송신을 goods key별로 직렬 수행합니다.
- A22 쇼핑몰상품옵션전송은 더 이상 이 자동화 경로에서 사용하지 않습니다.

2) 옵션 없는 단품
- A4 상품조회수정: goods key 정확 검색 → 정확 일치 1행만 선택 → 상품상태 품절/판매중 전환
- A21 쇼핑몰상품수정: 같은 goods key 정확 검색 → 상품 수정전송 → 상품판매상태송신 → 품절/판매중 선택 → 상품수정 송신 → 최종 완료문구 확인
- 단품은 A6 옵션상태 변경을 사용하지 않습니다.

v0.1.7 실패건 재시도 상태 복구
- 서버 원장에는 FAILED가 확정됐는데 확장 내부 storage에 같은 job의 RUNNING 상태가 남으면 Commerce OS가 실행목록을 숨길 수 있었습니다.
- v0.1.7은 Commerce OS 페이지에 연결될 때 확장 내부 RUNNING 시작시간과 같은 job의 마지막 종료결과 finishedAt을 비교합니다.
- 같은 job이고 마지막 결과가 SUCCEEDED/FAILED/UNCERTAIN이며 finishedAt이 RUNNING 시작시간 이상일 때만 그 RUNNING 상태를 오래된 잔여상태로 판단해 자동 정리합니다.
- 새 재시도가 실제로 시작되어 RUNNING 시작시간이 이전 실패 finishedAt보다 최신이면 절대 정리하지 않습니다.
- 재고 0 기준점, 정확재고, Shopling 상품상태 자체는 이 복구에서 변경하지 않습니다.

v0.1.6 A6 검색 시작 보완
- 실제 A6 검색 전 화면의 [A6] 옵션대량수정 제목, 검색항목, 검색조건 select 안의 옵션자체관리코드를 함께 확인합니다.
- 위 세 증거가 있는 실제 작업 프레임에만 역할 마커를 추가하므로 좌측 메뉴 프레임을 A6로 오인하지 않습니다.
- A4/A6/A21 좌측 메뉴 클릭은 MAIN world bridge를 사용합니다.

안전 규칙
- 한 번에 한 B코드만 실행합니다.
- 같은 B코드의 품절과 판매중 작업은 동시에 실행하지 않습니다.
- A4/A21은 숫자 goods key가 없으면 시작하지 않습니다.
- 검색결과가 정확히 1행일 때만 상태변경/전송을 진행합니다.
- A4 상품상태 컨트롤을 안전하게 특정하지 못하면 임의 클릭하지 않고 FAILED로 중단합니다.
- A21 옵션상품은 옵션송신만, 단품은 상품판매상태송신만 선택합니다.
- 최종 완료문구 전에 성공 처리하지 않습니다.
- 실패건수 또는 제한시간 초과는 UNCERTAIN/FAILED로 남기고 수동 확인합니다.
- Chrome debugger 권한을 사용하지 않습니다.
- 확장프로그램은 1688 주문·결제, 가격, 상품명, 배송정보, 마켓 재고수량을 수정하지 않습니다.

설치/업데이트
1. Commerce OS 재고·품절·재입고 화면에서 v0.1.7 ZIP을 다운로드합니다.
2. ZIP 압축을 새 폴더에 풉니다.
3. chrome://extensions 에서 기존 v0.1.6을 제거하거나 비활성화합니다.
4. 압축해제된 v0.1.7 폴더를 로드합니다.
5. Commerce OS 재고·품절·재입고 화면과 로그인된 Shopling 탭을 모두 새로고침합니다.
6. BZZ341-1 재고 0 기준점은 다시 만들지 않습니다.
7. 기존 FAILED보다 오래 남은 확장 RUNNING 상태가 있으면 페이지 연결 시 자동 정리되고 BZZ341-1이 다시 1건 안전 실행 대상으로 보여야 합니다.
8. Shopling 메인화면에서 1건 안전 실행 후 A6 자동 진입 → 옵션자체관리코드 BZZ341-1 자동 검색을 확인합니다.
