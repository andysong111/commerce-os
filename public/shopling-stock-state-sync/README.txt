Commerce OS · Shopling Stock State Sync v0.2.1

목적
- Commerce OS 내부 재고수량을 Shopling/마켓의 재고수량과 맞추지 않습니다.
- Commerce OS가 계산한 목표상태가 품절 또는 판매중으로 바뀔 때 Shopling을 통해 마켓 판매상태만 반영합니다.
- Shopling 관리자 메인 메뉴 hover 자동화는 사용하지 않습니다.
- 로그인 후 A4/A6/A21 작업화면을 각각 별도 탭으로 열어두면 필요한 탭을 확장이 직접 찾아 사용합니다.

사용자가 열어둘 Shopling 작업탭
1. A4 상품조회수정
2. A6 옵션대량수정
3. A21 쇼핑몰상품수정
- 위 3개 탭이 열려 있고 로그인 세션이 살아 있으면 별도의 Shopling 관리자 메인화면 탭은 필요하지 않습니다.
- 옵션상품 실행 전에는 A6 + A21 탭을 모두 확인하고, 단품 실행 전에는 A4 + A21 탭을 모두 확인합니다.
- 필요한 탭이 없으면 Shopling 상태를 바꾸기 전에 FAILED로 중단합니다.

실행 경로
1) 옵션상품
- 고정 A6 탭: 옵션자체관리코드(B코드) 정확 검색 → 정확 일치 1행만 선택 → 옵션상태 품절/판매중 → 일괄 상태변경
- 고정 A21 탭: goods key 정확 검색 → 정확 일치 1행만 선택 → 상품 수정전송 → 옵션송신 선택 → 상품수정 송신 → 최종 완료문구 확인
- 동일 B코드에 활성 goods key가 여러 개면 A6는 1번만 수행하고 A21 옵션송신을 goods key별로 직렬 수행합니다.
- A22 쇼핑몰상품옵션전송은 사용하지 않습니다.

2) 옵션 없는 단품
- 고정 A4 탭: goods key 정확 검색 → 정확 일치 1행만 선택 → 상품상태 품절/판매중 전환
- 고정 A21 탭: 같은 goods key 정확 검색 → 상품 수정전송 → 상품판매상태송신 → 품절/판매중 선택 → 상품수정 송신 → 최종 완료문구 확인
- 단품은 A6 옵션상태 변경을 사용하지 않습니다.

v0.2.1 가격조정 확장 실행엔진 재사용
- 기존 가격조정 확장이 실제로 사용하는 chrome.scripting.executeScript(allFrames) 방식으로 모든 Shopling frame을 직접 읽어 A4/A6/A21 역할을 판정합니다.
- 작업 시작 직전에 필요한 고정 작업탭을 자동 새로고침해 이전 실행의 stale content-script/중복처리 메모리를 제거합니다.
- content worker가 응답하지 않으면 가격조정 확장처럼 해당 정확 frame에 worker를 동적으로 다시 주입한 뒤 작업을 전달합니다.
- 따라서 확장 업데이트 직후 오래 열린 탭, 이전 실패작업의 stale handler, content-script 미주입 때문에 시작 메시지만 뜨고 화면이 움직이지 않는 문제를 방지합니다.
- 메인화면 hover 메뉴 탐색은 다시 사용하지 않습니다.
- 작업 시작 전에 필요한 두 작업탭을 모두 확인해 반쪽 실행을 차단합니다.
- 제출 전 단계가 60초를 넘으면 FAILED로 종료합니다.

안전 규칙
- 한 번에 한 B코드만 실행합니다.
- 같은 B코드의 품절과 판매중 작업은 동시에 실행하지 않습니다.
- A4/A21은 숫자 goods key가 없으면 시작하지 않습니다.
- 검색결과가 정확히 1행일 때만 상태변경/전송을 진행합니다.
- A21 옵션상품은 옵션송신만, 단품은 상품판매상태송신만 선택합니다.
- 최종 완료문구 전에 성공 처리하지 않습니다.
- 실패건수 또는 제한시간 초과는 UNCERTAIN/FAILED로 남깁니다.
- Chrome debugger 권한은 이번 단계에서는 추가하지 않습니다. 최종 결과문구 탐지에서 실제 필요가 확인될 때만 가격조정 확장의 CDP 방식을 별도 적용합니다.
- 확장프로그램은 1688 주문·결제, 가격, 상품명, 배송정보, 마켓 재고수량을 수정하지 않습니다.

설치/테스트
1. Commerce OS 재고·품절·재입고 화면에서 v0.2.1 ZIP을 다운로드합니다.
2. ZIP 압축을 새 폴더에 풉니다.
3. chrome://extensions 에서 이전 Stock State Sync 버전을 제거하거나 비활성화합니다.
4. 압축해제된 v0.2.1 폴더를 로드합니다.
5. Shopling에서 A4/A6/A21 작업화면 3개를 각각 탭으로 열어둡니다.
6. Commerce OS 페이지를 새로고침합니다. v0.2.1은 실행 시 Shopling 작업탭을 자체적으로 한 번 새로고침하므로 사용자가 별도로 다시 새로고침할 필요는 없습니다.
7. BZZ341-1 재고 0 기준점은 다시 만들지 않습니다.
8. BZZ341-1 1건 안전 실행을 시작합니다.
9. 옵션상품 Canary는 A6 탭이 자동 새로고침된 뒤 활성화되어 BZZ341-1 검색을 시작하고, 이후 A21 탭으로 자동 전환되는지 확인합니다.
