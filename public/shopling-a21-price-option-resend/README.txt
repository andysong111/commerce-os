Commerce OS · Shopling A21 Price/Option Resend v0.1.0

목적
- Commerce OS에서 Shopling 가격 재조회까지 VERIFIED 된 GOODSKEY만 A21 쇼핑몰상품수정에서 마켓으로 수정전송합니다.
- 판매가 전송과 옵션 전송은 서로 다른 작업창/팝업으로 완전히 분리합니다.
- 판매가 전송은 A21의 '쇼핑몰별판매가'를 반드시 선택하고, 송신 팝업에서는 '판매가=수정'만 선택합니다.
- 옵션 전송은 '옵션송신' 모드와 '옵션송신=선택'만 사용합니다.

안전장치
1) A21 목록 화면이 아니면 시작하지 않습니다.
2) Commerce OS 가격 재조회 상태가 VERIFIED가 아니면 대상 자체를 내려주지 않습니다.
3) 검색은 최대 200 GOODSKEY씩 시작합니다.
4) 화면출력은 500으로 맞추고 실제 조회수가 500건을 넘으면 전송 전에 묶음을 반으로 자동 분할합니다.
5) 검색한 모든 GOODSKEY가 결과에 있어야 하며, 총 조회수와 안전하게 식별한 선택행 수가 정확히 같아야 전송합니다.
6) 판매가/옵션 이외 항목은 수정하지 않습니다.
7) 결과 화면에서 성공을 확인하지 못하면 성공으로 기록하지 않습니다.
8) 동시 작업창은 최대 4개입니다.

사용
1) Chrome 확장프로그램 관리(chrome://extensions)에서 개발자 모드를 켭니다.
2) ZIP 압축을 풀고 '압축해제된 확장 프로그램을 로드합니다'로 이 폴더를 선택합니다.
3) Shopling 로그인 후 [A]상품 > [21] 쇼핑몰상품수정(A21) 목록 화면을 엽니다.
4) 확장프로그램 아이콘을 눌러 대상 205/205 등 VERIFIED 표시를 확인합니다.
5) 'A21 병렬 수정전송 시작'을 누릅니다.
6) 작업 중 창을 임의로 닫지 않습니다. 실패 건은 확장 팝업에 남습니다.

주의
- 이 확장프로그램은 A21 마켓 수정전송을 실제 실행합니다.
- 설치만으로 자동 실행되지 않으며 사용자가 시작 버튼을 눌러야 합니다.
