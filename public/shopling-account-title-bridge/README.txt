Commerce OS Shopling Account Title Bridge v0.2.1

목적:
Shopling에 로그인한 Chrome의 상품조회 메인 화면에서 현재 조회된 상품 전체의 goods key를 자동 수집하고, 같은 goods key 안의 같은 쇼핑몰 여러 로그인 ID에 동일 상품명이 반복되는 경우만 계정별로 분산한 뒤 Shopling에 저장하고 재검증합니다.

원칙:
- 상품조회 메인 화면에 '미분산 상품 일괄 처리' 버튼 하나만 표시합니다.
- 현재 조회조건의 결과 전체를 대상으로 합니다. 페이지 번호가 있으면 같은 조회조건의 다른 페이지도 읽습니다.
- 전체 조회수보다 goods key 수집량이 적으면 일부만 처리하지 않고 안전하게 중단합니다.
- 일반 상품수정 팝업에는 일괄 처리 버튼을 표시하지 않습니다.
- 쇼핑몰별 상품명등록 화면을 직접 연 경우에만 개별 '분산·저장' 버튼이 표시됩니다.
- Shopling 공식 API의 goods_key + mall_id 적용 결과는 그대로 존중합니다.
- 빈 상품명은 새로 만들지 않습니다.
- 이미 채워진 동일 쇼핑몰/동일 상품명만 대상으로 합니다.
- 새로운 키워드를 발명하지 않고 기존 검증 상품명의 단어 순서만 계정별로 다르게 배치합니다.
- UTF-8 100bytes 제한을 넘기지 않습니다.
- 가격, 옵션, 검색어, 이미지, 상세설명은 수정하지 않습니다.
- Shopling 비밀번호나 쿠키를 외부 서버에 저장하거나 전송하지 않습니다.
- 이미 분산된 goods key는 자동으로 건너뜁니다.
- 저장 후 해당 goods key를 다시 열어 동일 쇼핑몰 중복이 사라졌는지 자동 확인합니다.

설치:
1. ZIP 파일을 다운로드한 뒤 압축을 풉니다.
2. 압축을 푼 폴더를 열었을 때 manifest.json이 바로 보여야 합니다.
3. Chrome 주소창에서 chrome://extensions 를 열고 개발자 모드를 켭니다.
4. 기존 Commerce OS Shopling Account Title Bridge가 있으면 삭제합니다.
5. '압축해제된 확장 프로그램을 로드'를 누르고 manifest.json이 바로 들어 있는 폴더를 선택합니다.

일괄 사용:
1. Shopling에 로그인한 상태로 [사입] 상품조회/수정 메인 화면에서 원하는 검색조건으로 조회합니다.
2. 상품조회 결과 영역 우측 아래에 '미분산 상품 일괄 처리' 버튼이 표시됩니다.
3. 버튼을 한 번 누르면 현재 조회결과 전체의 goods key를 수집합니다.
4. 조회결과 전체 수량과 수집 goods key 수가 맞는지 먼저 확인합니다. 맞지 않으면 일괄 실행하지 않고 중단합니다.
5. 백그라운드 탭 하나가 goods key를 순서대로 열어 같은 쇼핑몰 로그인 ID의 중복 상품명을 검사합니다.
6. 이미 분산된 상품은 저장 없이 건너뜁니다.
7. 미분산 상품은 기존 키워드 순서만 계정별로 다르게 배치한 뒤 Shopling 저장을 실행합니다.
8. 저장 후 같은 goods key를 다시 열어 중복이 사라졌는지 검증하고 다음 상품으로 넘어갑니다.
9. 원래 상품조회 메인 화면의 상태창에서 전체/완료/분산저장/기존정상/확인필요 수량을 볼 수 있습니다.

개별 사용:
- 쇼핑몰별 상품명등록 화면을 직접 연 경우에는 우측 아래 '분산·저장' 버튼 하나만 보입니다.
- 누르면 현재 goods key의 중복 상품명만 분산하고 즉시 Shopling 저장을 실행합니다.

v0.2.1:
- Shopling 상품조회 결과가 내부 frame에서 렌더링되는 구조를 지원합니다.
- '미분산 상품 일괄 처리' 버튼을 상품조회 메인 결과 frame에 표시합니다.
- 일반 상품수정 팝업에 잘못 보이던 일괄 버튼을 제거합니다.
- 총 조회수 대비 goods key 수집량이 부족하면 일부 실행을 막는 안전장치를 추가합니다.

v0.2.0:
- '미리 분산' 버튼을 제거하고 버튼 하나로 통합했습니다.
- Shopling 상품목록에서 goods key를 일괄 수집합니다.
- 미분산 goods key만 백그라운드에서 순차 처리합니다.
- 저장 후 재접속 검증을 추가했습니다.
- 이미 정상 분산된 상품은 자동 건너뜁니다.
- 상품 하나씩 사람이 열 필요가 없습니다.

v0.1.1:
- ZIP 내부의 불필요한 한 단계 중첩 폴더를 제거했습니다.
