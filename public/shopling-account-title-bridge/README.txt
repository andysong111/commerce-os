Commerce OS Shopling Account Title Bridge v0.4.0

목적:
Shopling에 로그인한 Chrome에서 상품명 일괄 분산과 마켓 등록 전송을 이어서 처리합니다. 상품명 분산은 기존 v0.3.1 안전장치를 유지하고, 새 마켓 자동전송은 DM1~SM2 자사상품코드 그룹의 쇼핑몰 미등록 상품만 조회해 저장된 검색관리와 1:1로 연결합니다.

핵심 원칙:
- Shopling 로그인 세션은 사용자의 Chrome 안에서만 사용합니다.
- 비밀번호나 쿠키를 Commerce OS 서버로 전송하지 않습니다.
- 상품명 분산과 마켓 송신은 별도 버튼으로 분리해 의도하지 않은 자동 판매 전송을 방지합니다.
- 마켓 자동전송은 쇼핑몰 미등록 상품만 대상으로 합니다.
- 판매 채널 매핑은 DM1→도매1, DM2→도매2, DM3→도매3, DM4→도매4, SM1→소매1, SM2→소매2로 고정합니다.
- Shopling이 한 화면에서 동시 송신을 제한하므로 Chrome 작업 창을 최대 2개까지만 병렬로 사용합니다.
- 화면 구조나 저장 검색 결과가 예상과 다르면 임의 클릭하지 않고 '확인필요'로 종료합니다.
- 송신 버튼을 누른 이후 결과가 불명확한 건은 중복 재송신하지 않습니다.

상품명 분산:
1. 상품조회 메인 화면의 '미분산 상품 일괄 처리' 버튼을 누릅니다.
2. 현재 조회조건의 모든 goods key를 수집합니다. 총 조회수보다 적게 수집되면 일부 실행하지 않고 중단합니다.
3. 같은 쇼핑몰의 동일 상품명만 분산하고 저장합니다.
4. Shopling 제목 토큰으로 부족하면 Commerce OS SEO 원장의 검증 후보를 마지막 fallback으로 사용합니다.
5. 저장 후 같은 goods key를 다시 열어 중복 잔존 여부를 검증합니다.
6. timeout/저장검증 실패 등은 최대 2회 자동 재시도합니다.

마켓 자동전송:
1. 상품명 미분산 일괄 처리가 끝난 뒤 같은 Shopling 상품조회 화면에서 '마켓 자동전송 시작 · 동시 2창'을 누릅니다.
2. 작업큐는 다음 6개만 생성합니다.
   - DM1 → 도매1
   - DM2 → 도매2
   - DM3 → 도매3
   - DM4 → 도매4
   - SM1 → 소매1
   - SM2 → 소매2
3. 각 작업창에서 자사상품코드 조건과 '쇼핑몰에 미등록된 상품' 조건을 자동 적용해 조회합니다.
4. 미등록 상품이 0개면 해당 채널은 자동 건너뜁니다.
5. 조회된 상품을 선택하고 '쇼핑몰 상품등록하기'를 실행합니다.
6. 쇼핑몰 아이디 선택 화면에서 작업에 대응하는 저장 검색관리(도매1~소매2)를 적용합니다.
7. 저장 검색 적용 후 대상 행이 자동 선택되어 있으면 그대로 진행합니다. 선택이 비어 있더라도 저장 검색으로 12행 이하까지 안전하게 좁혀진 경우에만 보이는 행을 선택합니다. 그보다 많으면 전체 계정 오송신 위험 때문에 '확인필요'로 멈춥니다.
8. 쇼핑몰 연동 정보 선택 화면에서는 현재 운영 기준을 명시적으로 맞춥니다.
   - 쇼핑몰별 상품판매가
   - 상품설명
   - 쇼핑몰별 상품명
   - 검색어
   - 옵션명
   - 매핑 카테고리가 없으면 무시하고 쇼핑몰 기본정보의 카테고리로 전송
9. '상품등록송신'을 클릭하고 Shopling 성공/실패 화면 또는 송신창 종료를 확인합니다.
10. 송신 전 단계의 timeout/창 오류는 1회 자동 재시도합니다. 송신 클릭 이후 결과가 불명확하면 중복등록 위험 때문에 재시도하지 않고 '확인필요'로 남깁니다.

동시 처리:
- 최대 2개의 독립 Chrome 창을 사용합니다.
- 예: Lane 1에서 DM1→도매1, Lane 2에서 DM2→도매2를 처리합니다.
- 한 Lane이 끝나면 다음 DM3/DM4/SM1/SM2 작업을 자동으로 이어받습니다.
- 마지막에 송신/미등록없음/확인필요/실패 건수를 상품조회 화면 패널에 표시합니다.

설치:
1. Commerce OS의 Shopling bridge ZIP을 다운로드하고 압축을 풉니다.
2. chrome://extensions 에서 개발자 모드를 켭니다.
3. 기존 Commerce OS Shopling Account Title Bridge를 삭제하거나 새 버전 폴더로 다시 로드합니다.
4. '압축해제된 확장 프로그램을 로드'로 manifest.json이 있는 폴더를 선택합니다.

v0.4.0:
- Shopling prodlinkage 상품등록 흐름 자동화를 추가했습니다.
- DM1~SM2와 도매1~소매2를 1:1 고정 매핑합니다.
- 최대 2개 Chrome 창 병렬 작업큐를 추가했습니다.
- 미등록 상품 0건 자동 건너뜀, 송신 전 1회 재시도, 송신 후 중복 재시도 금지 정책을 추가했습니다.
- 쇼핑몰 아이디 저장검색이 과도한 계정 행을 노출하면 자동 송신하지 않는 fail-closed 안전장치를 추가했습니다.

v0.3.1:
- Shopling 화면의 키워드만으로 부족한 상품은 Commerce OS Supabase SEO 원장의 최신 검증 후보를 읽어 마지막 fallback으로 사용합니다.
- extension background에서만 Commerce OS read-only keyword-pool API를 호출하며 Shopling 쿠키/비밀번호는 전송하지 않습니다.
- 기존 v0.3.0 자동 재시도와 실패 상세기록은 그대로 유지합니다.
