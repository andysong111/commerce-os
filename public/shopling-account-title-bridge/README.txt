Commerce OS Shopling Account Title Bridge v0.1.1

목적:
Shopling 상품수정 > 쇼핑몰별 상품명등록 화면에서 한 goods_key 안의 같은 쇼핑몰에 여러 로그인 ID가 있을 때 동일 상품명이 반복되는 문제를 보정합니다.

원칙:
- Shopling 공식 API의 goods_key + mall_id 적용 결과는 그대로 존중합니다.
- 빈 상품명은 새로 만들지 않습니다.
- 이미 채워진 동일 쇼핑몰/동일 상품명만 대상으로 합니다.
- 새로운 키워드를 발명하지 않고 기존 검증 상품명의 단어 순서만 계정별로 다르게 배치합니다.
- UTF-8 100bytes 제한을 넘기지 않습니다.
- 다른 상품 필드, 가격, 옵션, 검색어, 이미지, 상세설명은 수정하지 않습니다.
- Shopling 비밀번호나 쿠키를 서버에 저장하지 않습니다. 사용자가 이미 로그인한 Chrome 세션 안에서만 작동합니다.

설치:
1. ZIP 파일을 다운로드한 뒤 압축을 풉니다.
2. 압축을 푼 폴더를 열었을 때 manifest.json이 바로 보여야 합니다.
3. Chrome 주소창에서 chrome://extensions 를 열고 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드'를 누른 뒤 manifest.json이 바로 들어 있는 그 폴더를 선택합니다.

사용:
1. 확장프로그램을 설치한 뒤 Shopling 쇼핑몰별 상품명등록 팝업을 엽니다.
2. 동일 쇼핑몰의 중복 제목이 있으면 자동으로 '미리 분산'되어 보라색 테두리로 표시됩니다. 이 단계에서는 서버에 저장되지 않습니다.
3. 확인 후 우측 아래 '분산 후 저장'을 누르면 Shopling의 기존 저장 버튼을 호출합니다.
4. 문제가 있으면 팝업을 닫으면 됩니다. 저장 전에는 Shopling 서버 값이 바뀌지 않습니다.

v0.1.1:
- ZIP 내부의 불필요한 한 단계 중첩 폴더를 제거했습니다.
- Windows에서 일반 압축 해제 후 생성된 폴더를 그대로 Chrome에서 선택하면 manifest.json을 즉시 찾을 수 있습니다.

v0.1.0:
- 동일 쇼핑몰의 여러 로그인 ID 제목 중 정확히 같은 제목만 감지합니다.
- 기존 단어 집합을 보존한 결정론적 순열을 생성합니다.
- 제목이 한 단어이거나 안전한 고유 순서를 충분히 만들 수 없으면 억지로 변경하지 않습니다.
- native Shopling 저장 버튼 탐지는 사용자가 '분산 후 저장'을 명시적으로 눌렀을 때만 실행합니다.
