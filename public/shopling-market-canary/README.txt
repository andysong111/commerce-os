Commerce OS Shopling Market Canary v0.1.0

목적
- 전체 자동화가 아니라 Chrome 확장프로그램으로 Shopling 상품 1건을 실제 마켓에 송신할 수 있는지 검증합니다.
- 대상은 대기 중인 DM1 → 도매1 딱 1건입니다.
- 상품명 분산, 18건 대량처리, 동시 2창은 이번 테스트에서 제외합니다.

안전장치
- 정확한 ptn_goods_cd 한 건만 조회합니다.
- Shopling에서 쇼핑몰 미등록 상태를 다시 확인합니다.
- 상품등록송신 직전에 Commerce OS 영구 submit lock이 성공해야 클릭합니다.
- 송신 전 실패는 Canary 원장을 자동으로 queued 상태로 원복합니다.
- submit lock 이후 결과가 불명확하면 자동 재전송하지 않고 확인필요로 남깁니다.

사용법
1. 기존 Commerce OS Shopling 확장프로그램은 테스트 중 비활성화합니다.
2. 이 Canary 확장프로그램을 압축해제 방식으로 로드합니다.
3. Shopling [사입] 상품조회/수정 화면을 엽니다. 별도 상품 검색은 필요 없습니다.
4. 빨간색 '마켓 전송 1건 실전테스트 · DM1→도매1' 버튼을 딱 한 번 누릅니다.
5. 작업창 1개가 열리며 정확 자사상품코드 조회 → 미등록 확인 → 도매1 연동설정 → 상품등록송신을 시도합니다.
6. 최종 결과 화면을 캡처합니다.

판정
- 신규송신 1: 확장프로그램 기반 마켓 전송 가능성이 실전으로 증명됨.
- 이미등록/미등록없음 1: 중복방지가 정상 작동했으나 실제 송신 검증은 다른 미등록 건으로 재시험 필요.
- 실패 1: 송신 전 DOM/화면 자동화 실패. 대상은 자동 재대기됨.
- 확인필요 1: 송신 경계를 지난 뒤 결과가 불명확. 절대 자동 재전송하지 않음.
