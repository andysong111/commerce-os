Commerce OS Shopling Market Canary v0.1.2

목적
- Chrome 확장프로그램으로 Shopling 상품 1건을 실제 마켓에 송신할 수 있는지 검증합니다.
- 대상은 대기 중인 DM1 → 도매1 딱 1건입니다.
- 상품명 분산, 18건 대량처리, 동시 2창은 이번 테스트에서 제외합니다.

이번 버전의 핵심
- 새 Chrome 작업창을 임의 생성하지 않습니다.
- 사용자가 실제로 성공시키는 수동 경로를 그대로 복제합니다.
  1) 현재 상품조회/수정 화면의 '쇼핑몰 미등록 검색'
  2) 정확한 자사상품코드 1건 조회/선택
  3) '쇼핑몰 상품등록하기' 클릭
  4) Shopling이 띄운 goods_mallReg_idChoice.phtml에서 검색관리 '도매1' 적용 후 상단 '선택'
  5) goods_mallReg_preProdChoice.phtml에서 검색관리 '도매1' 적용
  6) 쇼핑몰별 상품판매가 / 상품설명 / 쇼핑몰별 상품명 / 검색어 / 옵션명 / 매핑된 카테고리로 전송 / 매핑없음 기본카테고리 사용 확인
  7) Commerce OS 영구 submit lock 성공 후 '상품등록송신' 클릭

안전장치
- 정확한 ptn_goods_cd 한 건만 대상으로 합니다.
- Shopling의 '쇼핑몰 미등록 검색' 경로를 사용합니다.
- 상품등록송신 직전에 Commerce OS 영구 submit lock이 성공해야 클릭합니다.
- 송신 전 실패는 Canary 원장을 자동으로 queued 상태로 원복합니다.
- submit lock 이후 결과가 불명확하면 자동 재전송하지 않고 확인필요로 남깁니다.
- DOM 인식 실패 시 Shopling 팝업을 강제로 닫지 않습니다.

사용법
1. 기존 Commerce OS Shopling 확장프로그램은 테스트 중 비활성화합니다.
2. Canary v0.1.2를 압축해제 방식으로 로드합니다.
3. Shopling [사입] 상품조회/수정 화면을 엽니다. 별도 상품 검색은 필요 없습니다.
4. 빨간색 '마켓 전송 1건 실전테스트 · DM1→도매1' 버튼을 딱 한 번 누릅니다.
5. 현재 화면과 Shopling이 직접 띄우는 팝업이 자동으로 진행되는지 관찰합니다.
6. 실패/확인필요가 나오면 다시 누르지 말고 해당 화면을 캡처합니다.

판정
- Canary 성공: 확장프로그램 기반 Shopling→도매1 실제 송신이 실전으로 증명됨.
- 이미등록/미등록없음: 중복방지가 정상 작동했으나 실제 송신 검증은 다른 미등록 건으로 재시험 필요.
- 송신 전 실패: DOM/화면 자동화 실패. 대상은 자동 재대기됨.
- 확인필요: 송신 잠금/클릭 이후 결과가 불명확. 절대 자동 재전송하지 않음.
