Commerce OS · Shopling 재고상태 전환 v0.1.0

목적
- 품절 확인 B코드: Commerce OS 재고 기준점 0 확정 후 Shopling 품절 반영
- 확정입고 후 정확재고가 양수: Shopling 판매중 복구

처리 경로
1. 옵션상품
   - A6 옵션대량수정에서 옵션자체관리코드 B코드 검색
   - 옵션상태를 품절 또는 판매중으로 일괄 변경
   - A22 쇼핑몰상품옵션전송에서 동일 B코드 검색
   - 상품옵션전송 완료 확인

2. 옵션 없는 단품
   - A6 옵션대량수정에서 B코드 상태를 품절 또는 판매중으로 변경
   - A21 쇼핑몰상품수정에서 모델번호를 검색
   - 상품판매상태송신에서 품절 또는 판매중 선택
   - 상품수정 송신 완료 확인

설치
1. 다운로드 ZIP 압축 해제
2. Chrome 주소창에 chrome://extensions 입력
3. 개발자 모드 켜기
4. 압축해제된 확장 프로그램을 로드합니다 선택
5. 압축을 푼 shopling-inventory-lifecycle 폴더 선택

운영 안전장치
- 한 번에 B코드 1개만 처리합니다.
- 재고 0 초기화와 Shopling 외부 반영은 분리 기록합니다.
- Shopling 반영 실패가 재고 0 사실을 되돌리지 않습니다.
- 단품은 모델번호가 없으면 실행하지 않습니다.
- 첫 운영은 옵션상품 1건과 단품 1건만 canary로 검증한 뒤 확대합니다.
