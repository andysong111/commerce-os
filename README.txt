Commerce OS · Shopling Stock State Sync v0.1.0

목적
- Commerce OS에서 실제 품절을 확인한 B코드의 Shopling 상태를 품절로 동기화합니다.
- 품절 0 기준점 이후 확정입고로 재고가 1개 이상이 되면 반대로 판매중으로 복구합니다.

실행 경로
1) 옵션상품
   A6 옵션대량수정: 옵션자체관리코드로 B코드 검색 → 옵션상태 품절/판매중 → 일괄 상태변경
   A22 쇼핑몰상품옵션전송: 동일 B코드 검색 → 상품옵션전송 → 최종 완료문구 확인

2) 옵션 없는 단품
   A6 옵션대량수정: 옵션자체관리코드로 B코드 검색 → 옵션상태 품절/판매중 → 일괄 상태변경
   A21 쇼핑몰상품수정: 모델번호 검색 → 상품 수정전송 → 상품판매상태송신 → 품절/판매중 → 상품수정 송신 → 최종 완료문구 확인
   단품은 A22 옵션전송만으로 품절/판매중을 확정하지 않습니다.

안전 규칙
- Commerce OS 화면의 1건 안전 실행에서만 시작합니다.
- 동시에 한 B코드만 실행합니다.
- 같은 B코드의 품절과 판매중 작업을 동시에 실행하지 않습니다.
- 정확 일치 B코드/모델번호 행만 선택하고 다른 행은 해제합니다.
- 최종 완료문구 전에 성공 처리하지 않습니다.
- Shopling 처리 완료 후 실패건수가 있거나 제한시간이 지나면 UNCERTAIN으로 기록하고 수동 확인을 요구합니다.
- Chrome debugger 권한을 사용하지 않습니다.
- 확장프로그램은 1688 주문·결제, 가격, 상품명, 배송정보를 수정하지 않습니다.

설치
1. ZIP 압축을 풉니다.
2. chrome://extensions 에서 개발자 모드를 켭니다.
3. 압축해제된 확장 프로그램을 로드합니다.
4. Commerce OS 재고·품절·재입고 화면과 로그인된 Shopling 탭을 새로고침합니다.
5. 실제 품절이 확인된 옵션상품 1건으로 먼저 검증합니다.
6. 단품 1건과 입고 후 판매중 복구 1건은 각각 별도 Canary로 검증합니다.
